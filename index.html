Frequently Asked Questions

Have questions? We have compiled the answers to the most common queries.

How does screen capture protection work?
BackDoor AI applies Win32 hardware capture affinity (`WDA_EXCLUDEFROMCAPTURE`) to the HUD window. This tells the Windows DWM to omit rendering the HUD window contents on any print screen, screen recording, or video calling software (Zoom, Teams, Meets, Discord). Your screen shares will show only what is behind the HUD.
Does it require an active internet connection?
No! BackDoor AI fully supports running 100% locally using offline LLM connections via Ollama. It will auto-detect pulled local models, prevent tray crashes by handling ports dynamically, and run local transcript/RAG lookups entirely on-device.
Where are my API credentials stored?
API keys are encrypted using Windows DPAPI and stored securely inside the Windows Credential Manager under the service name `BackDoorAI`. They are never saved in plaintext on disk, localStorage, or frontend memory, ensuring complete privacy.
What global shortcuts are available?
- `Alt + Shift + W`: Toggles the main workspace dashboard.
- `Alt + I`: Toggles the Stealth HUD Overlay.
- `Alt + Q`: Triggers a Quick Answer using audio transcription.
- `Alt + S`: Captures screen area, runs OCR, and generates code solutions.
- `Alt + H`: Cycles HUD opacity (Solid, Glass, Ghost).
- `Alt + C`: Clears the HUD history.
